# Google Stitch Design Prompt — Karigar.ai Mobile App (Customer Side)

A modern, trustworthy, and polished mobile service-booking app for Pakistan's urban users. Users find home service providers through natural language (English, Urdu, Roman Urdu), get AI-powered transparent matching with reasoning, book services with clear pricing, track service lifecycle in real-time, and leave feedback. The app must feel human-crafted, premium, and consistent across every single screen.

---

## DESIGN SYSTEM & GLOBAL RULES (Apply to ALL screens)

**Vibe:** Professional, trustworthy, warm, and effortless. Think of a well-designed fintech app — not flashy, not cold. It should feel like a premium Pakistani product, not a generic template.

**Color Palette:**
- Primary: Deep teal (#0D7377) for buttons, active states, and key highlights
- Secondary: Warm coral (#FF6B6B) for urgency badges, alerts, and accent CTAs
- Background: Off-white (#FAFAFA) for all screen backgrounds — never pure white
- Surface: White (#FFFFFF) for cards, modals, and elevated containers with subtle shadow
- Text Primary: Charcoal (#1A1A2E) for headings and body text
- Text Secondary: Slate gray (#64748B) for captions, labels, and helper text
- AI Accent: Soft mint (#E8FFF5) with teal border for Antigravity reasoning boxes
- Success: Emerald (#10B981) for confirmations and completed states
- Warning: Amber (#F59E0B) for scheduling conflicts and alerts
- Error: Rose (#EF4444) for dispute states and errors

**Typography:**
- Headings: Medium-weight geometric sans-serif (like Plus Jakarta Sans or General Sans), tracking slightly tight
- Body: Regular-weight clean sans-serif (like Inter), generous line height for readability
- Captions/Labels: Uppercase letterspaced labels only for section dividers, never for body content

**Element Styling:**
- Buttons: Large (48px height minimum), rounded corners (12px radius — not fully pill-shaped), strong shadow on primary buttons
- Cards: 16px padding, 12px border radius, subtle drop shadow (0 2px 8px rgba(0,0,0,0.06))
- Input fields: 48px height, light gray border (#E2E8F0), 10px border radius, no background fill
- Icons: Outlined stroke style, 24px size, consistent 1.5px stroke width. Use a single icon set throughout (Phosphor or Lucide style)
- Spacing: 16px base grid, generous whitespace between sections (24px minimum)
- Status pills/badges: Small rounded rectangles (6px radius), filled background with matching text color

**Bottom Navigation Bar (present on screens: S04, S05, S09, S12, S13, S14, S15):**
- 4 tabs: Home (house icon), My Bookings (calendar icon), Notifications (bell icon), Profile (user circle icon)
- Background: White with a thin top border (#E2E8F0)
- Active tab: Teal icon + teal dot indicator below the icon (no text labels — icon only for cleanliness)
- Inactive tabs: Slate gray icons
- Height: 64px with safe area padding on bottom

**Status Bar:** Dark text on light background on all screens except Splash and Onboarding (which have light text on dark/colored backgrounds).

**Transitions & Flow:** All screens within the same flow (e.g., booking flow) must share the same header style, same spacing, same card treatment. No screen should feel like it belongs to a different app.

## DESIGN CONSISTENCY CHECKLIST (for the tool to follow)

1. Every screen with the bottom nav MUST use the exact same 4-tab bar (Home, My Bookings, Notifications, Profile) with identical icon style and sizing
2. All headers must use the same font size (18px for page titles), same weight, same back arrow icon
3. All primary CTA buttons must be the same height (48px), same teal color, same border radius (12px), same font size (16px white text)
4. All cards across the app must have the same border radius (12px), same shadow, same padding (16px)
5. The Antigravity/AI reasoning boxes must ALWAYS use the same mint green background + teal left border treatment
6. Provider cards must look identical whether they appear on S05, S06, S09, S10, or S15
7. Status pills/badges must use consistent colors: Emerald for positive/completed, Amber for in-progress/warning, Rose for negative/cancelled, Teal for neutral/info
8. Icon style must be consistent throughout: outlined, 1.5px stroke, same icon family on every screen
9. Typography hierarchy must not change between screens: 22px for page titles, 18px for section headers, 16px for card titles, 14px for body, 13px for secondary, 12px for captions, 11px for tiny labels
10. Spacing between sections must always be 24px. Card internal padding always 16px. Screen horizontal margins always 16px.
