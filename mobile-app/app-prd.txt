PRODUCT REQUIREMENTS DOCUMENT (PRD)


App  Name: Karigar.ai


\1.  Product Overview
Problem
Users rely on informal channels (calls, WhatsApp, referrals) to find service providers → leads to:
* Poor matching
* Unclear pricing
* No scheduling system
* Low trust
* No feedback loop
Solution
A mobile app powered by an Antigravity orchestration engine that:
* Understands natural language requests
* Matches best providers
* Generates transparent pricing
* Simulates booking, tracking, feedback, and dispute resolution


2. Target Users
Primary:
* Urban households (Pakistan)
* Students / families needing home services
Secondary:
* Local service providers (technicians, tutors, etc.)


3 Core Features (MVP Scope)
4.1 Smart Request Input
Description:
User enters request in natural language through text or voice based inputs.
Input Examples:
* “AC kaam nahi kar raha kal subah”
* “Need plumber urgent DHA”
* “Fan repair cheap please”
Requirements:
* Accept:
   * Urdu
   * Roman Urdu
   * English
* Extract:
   * Service type
   * Location
   * Time
   * Urgency
   * Budget hint
4.2  Provider Discovery
Data Source:

Provider Schema:{
"service": "AC Repair",

"urgency": "High",
"time": "Tomorrow Morning",
"budget": "Low",
"confidence": 0.87
}
Edge Case:
* If confidence < 0.7 → ask clarification

4.4 💰 Dynamic Pricing
Formula:
Total Price =
Base Fee +
(Distance * cost_per_km) +
Urgency Fee +
Demand Surge
Example:
Base Fee: 1500
Distance Cost: 200
Urgency: +300
Total: 2000 PKR
Requirements:
* Show breakdown clearly
* Suggest cheaper alternative
________________


4.5 Scheduling
Features:
* Show available slots
* Prevent double booking
* Add travel buffer (30–60 mins)
Edge Cases:
* No slot available → suggest alternatives
* Provider busy → auto-select next best provider
