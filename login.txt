================================================================
LOGIN API CONTRACT
================================================================

ENDPOINT:   POST /api/auth/login
HEADERS:    Content-Type: application/json


----------------------------------------------------------------
REQUEST BODY
----------------------------------------------------------------

{
  "email": "alex@provider.com",
  "password": "yourpassword123"
}

Fields:
  - email     (string, required) : Registered email address
  - password  (string, required) : User password (min 8 chars)


----------------------------------------------------------------
RESPONSE — SUCCESS (200 OK)
----------------------------------------------------------------

{
  "success": true,
  "message": "Login successful",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": "usr_123",
      "name": "Alex Khan",
      "email": "alex@provider.com",
      "role": "service_provider",
      "avatar": "https://..."
    }
  }
}


----------------------------------------------------------------
RESPONSE — INVALID CREDENTIALS (401 Unauthorized)
----------------------------------------------------------------

{
  "success": false,
  "message": "Invalid email or password",
  "data": null
}


----------------------------------------------------------------
RESPONSE — VALIDATION ERROR (422 Unprocessable Entity)
----------------------------------------------------------------

{
  "success": false,
  "message": "Validation failed",
  "errors": {
    "email": "Email is required",
    "password": "Password must be at least 8 characters"
  }
}


----------------------------------------------------------------
RESPONSE — SERVER ERROR (500 Internal Server Error)
----------------------------------------------------------------

{
  "success": false,
  "message": "Internal server error",
  "data": null
}


================================================================
NOTES
================================================================

- The returned "token" is a JWT. Store it in localStorage or
  an httpOnly cookie for subsequent authenticated requests.

- For protected routes, send the token in the header:
    Authorization: Bearer <token>

- Token expiry is typically 24h. Implement refresh token logic
  if needed.

================================================================
