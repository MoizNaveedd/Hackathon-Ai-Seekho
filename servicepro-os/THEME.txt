================================================================
KARIGAR / SERVICE APP — THEME REFERENCE
(Copy this theme into the Admin Panel)
================================================================

Stack: Tailwind CSS v4 + shadcn + tw-animate-css
Font: Geist Variable (@fontsource-variable/geist)


----------------------------------------------------------------
1. CORE / BRAND COLORS
----------------------------------------------------------------
Primary (teal)............ #0D7377
Primary foreground........ oklch(0.985 0 0)   (near-white)

Used for: buttons, active nav items, accents, avatar ring.


----------------------------------------------------------------
2. SIDEBAR  (hardcoded Tailwind classes in Sidebar.tsx)
----------------------------------------------------------------
NOTE: The sidebar uses hardcoded Tailwind colors, NOT the
      --sidebar CSS variables.

Sidebar background........ #0F172A           (slate-900, dark navy)
Sidebar text (default).... white
Inactive nav item......... slate-400
Hover nav item............ white text + slate-800 bg
ACTIVE nav item........... #0D7377 bg + white text
Borders................... slate-800
Logout hover.............. rose-400 text + rose-500/10 bg
Avatar ring............... border #0D7377
Profile card bg........... slate-800/50  (hover: slate-800)
Width..................... 64 (256px) expanded / 20 (80px) collapsed
Collapse transition....... duration-300
Nav item transition....... duration-200


----------------------------------------------------------------
3. TYPOGRAPHY
----------------------------------------------------------------
Font family............... 'Geist Variable', sans-serif

Sidebar font sizes:
  App title............... text-lg (18px)  font-bold  tracking-tight
  Nav labels.............. text-sm (14px)  font-medium
  User name............... text-xs (12px)  font-semibold
  User role/subtitle...... text-[10px]     font-bold uppercase tracking-wider
  Nav icons............... 18px

----------------------------------------------------------------
8. HOW TO REPLICATE IN ADMIN PANEL
----------------------------------------------------------------
1. Install font:  @fontsource-variable/geist
2. Copy the @theme inline, :root, and .dark blocks from src/index.css
3. Reuse sidebar bg #0F172A with #0D7377 active/accent
4. Imports needed at top of index.css:
     @import "tailwindcss";
     @import "tw-animate-css";
     @import "shadcn/tailwind.css";
     @import "@fontsource-variable/geist";

Source files:
  - src/index.css
  - src/components/layout/Sidebar.tsx
